# 车载平衡滚球运动控制系统

2026 年全国大学生电子设计竞赛 — 基于立创庐山派 K230 系列的钢球检测与无线图传系统。

## 硬件架构

```
图传链路：  GC2093 → K230D → H.264/MJPEG → WiFi AP → PC

识别链路：  GC2093 → K230  → 图像处理 → UART → 主控板
```

两块板子独立工作，分别连接各自的摄像头。

| 子系统 | 硬件 | 核心功能 |
|--------|------|----------|
| 无线图传 | 庐山派 Lite K230D + GC2093 | 采集画面 → MJPEG/HTTP → WiFi AP 推流 |
| 钢球检测 | 庐山派 K230 + GC2093 | 识别钢球位置 → 偏移百分比 → UART 输出 |

## 快速开始

### 钢球检测端（K230）

1. CanMV IDE 打开 `k230-detector/main.py`
2. 运行 → 校准模式 → 将绿色凹槽对准绿框 → 按 USR 键
3. 自动标定 HSV → 进入识别模式
4. UART（GPIO 11 TX, GPIO 12 RX, 115200 波特率）输出 `[+12.3]` 格式偏移百分比
5. 无钢球时不发送数据

### 无线图传端（K230D）

1. CanMV IDE 打开 `k230-stream/main.py` → 保存到 SD 卡 `/sdcard/main.py`
2. K230D 上电 → 自动建立 WiFi 热点 `K230D_Ball`（密码 `12345678`）
3. PC 连接热点 → VLC 打开 `http://192.168.169.1/stream` 或浏览器打开 `http://192.168.169.1`

## 识别管线

```
BGR采集(320×240)
  → ROI提取(145行起, 300×15)
  → HSV绿色掩码(自动标定 + 余量)
  → 灰度图 × 非绿色掩码
  → OTSU自适应二值化(EMA平滑 α=0.05)
  → 形态学开运算(1×5横向核)
  → 面积过滤(10~250)
  → 形状过滤(宽高比0.6~1.7)
  → 贴边过滤(球形态豁免)
  → 跳变过滤(MAX_JUMP=20, LOST_TIMEOUT=20)
  → UART发送
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 检测分辨率 | 320×240 | |
| ROI | X=10 Y=145 W=300 H=15 | |
| HSV 余量 | H±8 S±20 V±30 | 标定时自动计算 |
| OTSU α | 0.05 | EMA 平滑系数 |
| 面积 | 10~250 | 最小/最大色块面积 |
| 宽高比 | 0.6~1.7 | 球形态范围 |
| 形态学核 | 1×5 矩形 | 断开横向反光粘连 |
| 跳变阈值 | 20 px | 相邻帧最大X位移 |
| 超时帧数 | 20 | 200ms 后重新搜索 |
| UART | 115200 8N1 | GPIO 11(TX) 12(RX) |
